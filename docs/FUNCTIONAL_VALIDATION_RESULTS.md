## 仍须如实保留：一次研究价值高估

v2 case5（正确的四条件交互卡）最初被评为 `substantial / retain`。理由主要是该合成系统的交互值尚未知、测完能回答原题；这不足以说明结果会改变重要解释、方法选择或边界认识。因而它通过了“没有硬错误”的检查，却暴露了**把普通未知事实高估为重要研究问题**的缺口。

随后补充价值校准，使用同一张已见正确卡进行 value-v3 真实复核。结果为 `routine / reject`，`decisive_findings=[]`：模型保留正确设计，指出其缺少具体决策后果，没有为了拒绝而编造科学错误。

这是一次已知案例上的校准修正。v2 的原始 `retain` 记录保留；value-v3 不能替代 v2 原始结果，也不能当作未见主题泛化或科研品味整体提高的证据。
