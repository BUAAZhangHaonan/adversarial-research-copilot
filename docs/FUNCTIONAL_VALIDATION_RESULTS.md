## 仍须如实保留：一次研究价值高估

v2 case5（正确的四条件交互卡）最初被评为 `substantial / retain`。理由主要是该合成系统的交互值尚未知、测完能回答原题；这不足以说明结果会改变重要解释、方法选择或边界认识。因而它通过了“没有硬错误”的检查，却暴露了**把普通未知事实高估为重要研究问题**的缺口。

随后补充价值校准，使用同一张已见正确卡进行 value-v3 真实复核。结果为 `routine / reject`，`decisive_findings=[]`：模型保留正确设计，指出其缺少具体决策后果，没有为了拒绝而编造科学错误。

这是一次已知案例上的校准修正。v2 的原始 `retain` 记录保留；value-v3 不能替代 v2 原始结果，也不能当作未见主题泛化或科研品味整体提高的证据。

## 新主题自然运行：闭环已执行，整卡尚未通过

独立新运行 `functional-20260908-natural.discover` 的题目是长链推理提前停止：不依赖外部裁判模型作停止决定、单卡 RTX 3090 可做初步验证、不训练大模型。材料准备 run 不算生成成功，下面也不把卡片的资源估计写成已完成研究实验。

**draw1：一次完整 cycle 已结束，最终 LEAD_ONLY / NEEDS_EVIDENCE。** 候选研究同模型的自报充分性分数 S 与强制作答可恢复性 R 的前缀边界是否错位，尝试区分概念滞后、长度伪影和基本对齐。初审发现作答者与答案解析器归因混淆、遗漏重要近邻，以及把“先正确再丢失”误作进入测量的必要条件。修订实际保存到 `card_46e10d0963134b67ac88456e865cbd6c` v2，复核确认上述三项已修。

复核仍给出 `substantial / revise`：新引文把 GPQA-D 的不同模型结果笼统写成“接近 0”，且纯位置信号可以有 AUC=1，现有规则却要求 AUC 接近 0.5 才判长度伪影，导致纯伪影被误判为混合机制；单一正确性类别内的 AUC 也未定义。这些问题仍在 v2 中，故没有把价值肯定当作科学通过，也未自动批准进入后续阶段。该例证明审查能提出反例并推动部分修订，同时也表明一次修订不能保证整卡正确。

**draw2：一次 cycle 已结束，最终 LEAD_ONLY / NEEDS_EVIDENCE。** 候选探索漂移事件附近的重审文本标记。ARC 初审自主找到 RPDI-EE 近邻，检出 LYNX 误归类，并提出错态本身也可能产生同样文本信号的竞争解释；实际修订加入近邻、纠正 LYNX、增加 never-correct 对照及定位分析，保存 `card_1e1565d118e44295a99787a0926e1df8` v2。随后复核仍为 `substantial / revise`，自主新增 f4（Terminator 被错误列入零训练文本方法）、f5（结果分类漏格）、f6（词典正控制不能证明语义检出有效）。**f4–f6 已发现但未修复**，不能把前三项 resolved 或 v2 保存当作整卡通过。

CodeX 的独立清单还指出：规则可能更早在正确段已停止，轨迹末尾错误稳定不能证明规则“按设计”提交错误答案；密度并非 RPDI 的熵比统计量，有限词表阴性不能否证全部文本路线；匹配与独立样本检验、≥5 条效力门控、后验定位与在线风险界仍未接通。它也指出复核建议的分类仍可能重叠，并且 ARC 把候选“不训练探针”误称用户不可删除条件；用户只要求不训练大模型。这些是 **CodeX 事后独立核对**，不能算作 ARC 已发现或修复。完整分阶段对照见私有 `work/NATURAL_DRAW2_INDEPENDENT_CHECKLIST.md`，该清单未输入本次模型任务。

draw2 conception 的已完成工具 trace 在 11:45 UTC 实际对 `src_earlystop_2606_02835v1` 使用 `read_record(limit=64000, offset=0)`，随后同源 `offset=64000` 成功，并定向检索近邻。初审读取范围核对也未见本地同源区间重复；一次空读与扩大远端抓取存在有限效率损失。这是具体分页与读取行为证据，不是 64K token，更不能单独覆盖全部费用预留和恢复测试。

**draw3：缓存首稿 v1 已接受，科学审查尚未结束。** 题目为“停在一个「稳定」的错误上”，试图用停止事件与自然终态的交叉表解释稳定型停止的准确率/有害过度思考异常。此前因候选新 claim 的补证请求绑定协议暂停；修复后复用已保存响应，已推进 `draw3.card_archive`，没有重新购买 conception。这里的接受是结构接受，不是科学推荐。
