新 discover 为按需调查 → Pro 连贯构思 → 科学审查 → 必要时一次定向修订与复核。旧 discover 和辩论代码仅恢复已存在的历史任务，新的默认流程不会调用它们。

技术契约通过不等于科学正确，更不等于新卡价值提高。合成正确卡可能被判断为普通题目；只有无依据地报告目标硬错误才算该配对的误判。错误卡则须给具体依据并实际改变错误正文，不能用风险附注代替修复。

本轮付费调用串行，沿用现有父账户。本轮起点已结算上界84.960337元，用户新授权剩余额度200.602047元；预留金额不是实际消耗。最终结果和新增实际费用将在真实运行结束后补齐，当前不宣称重构验收全部通过。
