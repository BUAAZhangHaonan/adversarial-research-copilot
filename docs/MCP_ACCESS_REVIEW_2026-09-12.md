## 现在的实际行为

1. 仅 search_literature 配置 allow_unmetered=true。费用上界继续为 null，调用和报告标明外部费用未计量。其他未知成本工具不会因此自动开放。
2. ScholarTrace 的无 URL 条目以前会被丢弃。现在保留题名、摘要和已返回的筛选理由，并标明身份未定位、不能正式引用；不为内部 paper_id 编造公开链接。
3. 默认 discover 和轻量候选的 develop/run 遇到文献阻塞时，只追加一次无工具收尾，复用冻结输入、已读片段和原草稿。保留受限线索或有依据地放下，不能把缺证升级为“值得讨论”。
4. 收尾仍失败时，只停放该候选，其他候选继续。原失败、未决请求和费用保留；恢复使用固定任务键，不重复发送原失败请求。模型响应未知、账单异常或环境变化不会被当作文献缺失吞掉。
5. 报告、润色输入和历史召回都能看到“文献受限，保留待查”。旧推荐不会冒充本次失败阶段的结论。正式运行不需要 CodeX 逐次介入。

历史完整研究卡路径仍使用原有显式重试；这次自动续行接在当前默认短流程及其两个后续预研阶段。

## 实际验证

- ScholarTrace 实际 query 一次，成功返回 3 篇候选。返回项缺少公开 URL/DOI/arXiv 标识；修正适配后仅回放同一原件，确认三条线索可见且不能正式引用，没有重复检索。
- 复用旧第五候选的 needs_evidence 响应，真实 deepseek-flash 完成一次有限收尾：ACCEPTED、lead，明确保留全文访问缺口；零工具动作，原失败响应仍未接受。模型费用 0.265752–0.265753 元。ScholarTrace 外部费用无法计量，因此不能给出本次总费用的完整数字。
- 离线检查覆盖：单卡缺证后继续下一卡、调研完全失败、收尾也失败、develop/run受限结果、恢复不重发、已读新来源可引用，以及计费异常不被吞掉。全量测试执行946项，945项通过；发现1处费用报告多显示了不适用的外部状态字段，修复后78项相关检查全部通过。

## 供后续 MCP 改进使用

ScholarTrace 优先返回稳定的论文标识或公开链接及计费信息；ScholarAnalysis 扩展 DOI、ACL 页面、PDF 直链的正文读取；webresearch 改善学术源代理访问、PDF 正文和错误分类。ARC 已能在这些能力暂时不足时完成受限交付，工具升级不需要先恢复一条无限等待的研究任务。
