## 已确认的软件与接口问题

首例 `discover-first-20260909.sample1` 完成共享调查、首条灵感和价值初筛，CHECK 已返回预研稿，但 `field_updates` 放在 `note` 内且根层为 null，未通过结构检查。随后一次 JSON 纠正请求被 DeepSeek 以 `BadRequestError`（HTTP 400）拒绝；没有收到流式 chunk。

冻结请求显示，这次纠正的 system/user 正文都没有 `json` 一词。DeepSeek 的 [JSON 模式文档](https://api-docs.deepseek.com/guides/json_mode/) 明确要求该词出现在指令中；[400错误说明](https://api-docs.deepseek.com/quick_start/error_codes/) 将其定义为请求格式错误。调查阶段纠正此前能成功，是因为其语法错误诊断碰巧包含 `Invalid JSON`。因此模板存在确定的请求前提缺失，与本次400吻合。原实现仅保存异常类型，没有保存错误body；不能声称已经读到供应商对此次拒绝的逐字解释。

已修正 Markdown 模板，并在适配层加付费前检查；不在代码里临时注入科研提示词。运行时同时开始保存 HTTP 状态、请求ID与错误body，便于下一次明确定位。相关修复走离线回归，第二例采用更新后的模板，未重买第一例的调查或预研。

首例运行与原任务仍保留暂停/失败状态。已生成但未接受的预研内容另存 `UNACCEPTED_CHECK_DRAFT.json/md`，仅排版供人阅读，不计入正式推荐数量。旧失败请求的15.912元预留仍保留，未根据缺失usage写成零，也未改写旧花费。第二个独立样例只在已知HTTP400拒绝、不存在活动请求且保留这笔费用负担的条件下开始；两个样例最坏合计仍不超过40元。

## 首例的研究内容

首条灵感是：在同一多模态任务中比较客观缺信息标签、内部必要性信号和实际求助行为的分歧。它有可理解的问题和论文入口，已能在完整协议生成前保存给人。

未接受的CHECK稿通过进一步阅读修正了 When2Tool 标签含义，将其区分为能力相对标签与客观信息缺口；也识别了版本与同名工作区别。这显示定向阅读确实产生了内容变化，而非只给出通过标签。

开发阅读仍发现以下风险，未将这些观察偷偷注入原任务，也未新增一轮付费审查：

- “目前没有任何工作对齐三者”“互不引用”等全域否定断言，无法由有限且部分仅摘要级的调查证明，应改为本次尚未找到。
- 单一RL设置中的奖励消融不能证明稠密信号是所有真实任务合理求助的必要条件。
- 三种标记的分歧可提供诊断线索，不能直接当作已经识别的知识/元认知/价值估计因果分解。高重合不能证明探针可替代策略训练；线性探针失败也不能证明表征中不存在相关信息。
- 更小的仿真载体是原型可行性入口，不能据此宣称已回答真实任务问题。原稿推荐 discuss 仍需由人判断是否值得优先投入。

## 第二例：调查内容与引用纠正失败

第二例在SURVEY停为 `PAUSED_PROTOCOL / INVALID_OUTPUT_AFTER_REPAIR`，未进入SKETCH。不是预算暂停，也不是等待用户的科学品味判断：它已结算1.516984元，当前阶段尚余18.483016元。

调查稿用 `arxiv:2107.04034` 等外部标识填写内部 `source_id`。20条SourceNote和2个补证请求的引用未注册。旧纠错反馈在每处错误重复大量裸ID，共215177字符，缺少标题/地址对应关系；纠正任务不开放检索，因此模型无法从这些ID重建映射。修复后的JSON模板成功得到响应，消除了第一例的请求前提缺失；但这一次响应仍保留外部ID，引用检查据实拒绝。

确定的诊断数据缺陷在本轮离线修复：给出与可见来源对应的有界标题/URL目录和精确匹配候选，而不猜测或自动接受未知引用。真实运行的原失败、原稿与费用仍保留；没有发起第三个样例或重买SURVEY。只读回放将反馈从215177减至21607字符（减少89.96%），20个外部ID中15个找到精确身份候选，其中2个有多表示/版本歧义；另5个未自动对应。原run/task仍暂停，38项相关回归通过。该回放只验证诊断可用性，没有让模型再次纠正，也不能据此预告续跑必然成功。

未接受稿尝试把“检测与定位变化、如何适应、将经验写回何处”连接起来；局部技能失效与复用/重学选择确实是可读的调查入口。但“传统RL都重置、符号经验全部保留”“无人打通完整回路”等断言把有限材料写成了全域判断，尚不可靠。导航变化检测路线未覆盖，也不能据此认定记忆复用机制缺席。部分方法只确认标题或摘要，却被放进较强的机制比较。这些切入点是SURVEY素材，未经过SKETCH/TRIAGE/CHECK，不能计作多张已推荐灵感。

本例原稿另存 `UNACCEPTED_SURVEY.json/md`。来源ID未接通，因此来源笔记的自报阅读层级也不当作已验证的正式记录。
