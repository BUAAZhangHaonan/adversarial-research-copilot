# 多模态大模型幻觉研究任务（开放探索版）

聚焦目标：围绕多模态大模型（MLLM）的幻觉问题，探索一种结合小波变换与表征流形的检测与编辑方法。

不预设唯一正确路线，不强制统一框架。鼓励先发散，再收敛。

---

## 1) 探索起点（可改写）

### 直觉
视觉幻觉通常表现为：模型生成的某些断言（对象/属性/关系/计数）**在图像/视频的多尺度结构上找不到支持**，并且对应的联合表征（视觉编码 + 语言隐状态）会落在“可信对齐样本”的流形之外。

### 可尝试的假设
- **H1（多尺度证据缺失）**：若某段文本断言确实由视觉证据支撑，则与该断言对应的图像区域在多尺度（小波子带）上应呈现与训练分布一致的结构统计；反之为高风险幻觉。
- **H2（流形外偏移）**：在“可信对齐样本”（真实图像-真实描述/答案）上学习到的联合表征流形内，样本具有较低的局部重构误差；幻觉样本在联合空间中更可能出现高重构误差/高局部离群度。

---

## 2) 方法方向（建议，不是硬模板）

### 2.1 输入与可观测量
- 输入：图像/视频 $x$，模型生成文本 $y$（caption/answer/chain-of-thought 可选），以及模型内部可取的中间量。
- 从 MLLM 取：
	- 视觉编码器 patch embedding：$V \in \mathbb{R}^{N\times d}$
	- 语言 token hidden state：$H \in \mathbb{R}^{T\times d}$
	- 跨注意力（可选）：$A \in \mathbb{R}^{T\times N}$（token->patch）

### 2.2 小波多尺度结构特征
对输入图像 $x$ 做 $L$ 层 2D DWT（视频可做“先逐帧 2D DWT + 时间 1D DWT”，或直接 3D 小波）。

对每层子带（$LL, LH, HL, HH$）在 patch 网格上计算结构统计向量 $w_i$：
- 子带能量与能量比
- 高频稀疏度（$\ell_1/\ell_2$ 比、top-k 能量占比）
- 局部方向性（$LH/HL$ 能量差）
- 多尺度一致性（相邻尺度能量的稳定性）

得到每个 patch 的小波特征 $W \in \mathbb{R}^{N\times m}$。

### 2.3 联合表征流形
构造联合表示：
$$z_i = [V_i \| W_i \| g(H, A, i)]$$
其中 $g(H, A, i)$ 把与 patch $i$ 相关的语言信息聚合进去，例如：
- $g=\sum_t A_{t,i} H_t$（注意力加权 token 表征）
- 或仅用 $\max_t A_{t,i}$ 作为“是否被引用”的强度，并与 $V_i,W_i$ 拼接

在训练/校准集（无幻觉或标注为 faithful）上，可先用一种简单方法刻画“局部流形”：
- **kNN + 局部 PCA**：对每个 $z_i$ 找 kNN，计算局部 PCA 重构误差 $r_i$。
- 也可探索 One-Class SVM、LOF、正态化流等替代方案。

得到 patch 级离群分数 $r_i$。

### 2.4 Token 级幻觉检测：把“断言”对齐到证据稀缺的区域
对每个 token/短语 $t$（可用依存句法或简单规则切分为名词短语/关系短语）：
- 取其注意力分布 $A_{t,:}$（没有注意力就用梯度/相似度替代）
- 定义该断言的“证据一致性分数”
$$s_t = \sum_i A_{t,i} \cdot \sigma(-r_i)$$
其中 $\sigma$ 是缩放函数。

直观解释：如果 token 强烈指向的区域全部是“流形外/多尺度异常”，那它更可能是幻觉。

输出：
- token/短语级幻觉概率 $p_t$（由 $s_t$ 和语言侧不确定性一起映射得到）
- 样本级分数 $S=\min_t s_t$ 或 top-k 最差断言聚合

---

## 3) 编辑（纠偏）方向：证据驱动改写 + 表征回拉

检测只是第一步；编辑目标是：**尽量保留非幻觉内容，只对高风险断言做“最小改写”。**

### 3.1 断言级改写（文本侧）
1) 识别高风险断言集合 $\mathcal{T} = \{t\mid p_t>\tau\}$
2) 生成一个“证据约束提示”（不给模型发挥空间去编造）：
- 列出每个 $t$ 对应的 top-attended patches
- 列出这些 patches 的 $r_i$（异常）和小波特征摘要（多尺度不支持）
3) 让模型优先做以下编辑策略（可按任务调整）：
- **删除**断言（如果没有任何视觉证据路径）
- **弱化**断言（从确定性断言改成不确定/范围更小）
- **替换**断言（从候选证据更强的类别/属性中选一个）

输出 edited 文本 $y'$。

### 3.2 表征投影（视觉-语言联合空间，可选）
对每个高风险 token $t$，计算其与视觉 patch 的对齐向量 $u_t=\sum_i A_{t,i} z_i$。

把 $u_t$ 投影到其 kNN 的局部 PCA 子空间，得到 $\hat{u}_t$，再用 $\hat{u}_t$ 作为解码时的“软约束”（例如作为额外上下文向量或作为重打分特征）。

直观解释：让模型的断言朝“可信流形”回拉，减少凭空编造。

## 4) 评测建议（先做最小闭环，再扩展）

### 4.1 数据集（先做检测/编辑，不做大而全）
- 幻觉检测：POPE、CHAIR（caption 幻觉）、MMHal-Bench（若可用）
- 任务可选：VQA / caption / grounded QA

### 4.2 指标
- 检测：AUROC / AUPRC（样本级与 token 级），以及在固定召回率下的误报率
- 编辑：
	- 幻觉率下降（CHAIR / POPE 指标）
	- 任务正确率不显著下降（或下降受控）
	- 最小改写度量（编辑距离/保留率）

### 4.3 Baseline（可从简起步）
- 语言侧自检：仅用 logprob/entropy 的不确定性检测
- 视觉侧 grounding：仅用 cross-attention mass 的 grounding score
- 我们的方法：grounding score +（小波一致性 + 流形离群）联合

### 4.4 失败判据（建议提前定义）
- 若在关键检测指标上没有稳定提升，可回退到更简单检测器并重做特征选择。
- 若编辑后幻觉下降但正确率明显受损，可改为更保守的“删除/弱化”策略。

---

## 5) 最小实现建议（工程可落地）

- 小波：用 PyWavelets 做 2D DWT（视频先逐帧）。
- 表征：从开源 MLLM 导出 patch embedding、token hidden state、cross-attention（拿不到 attention 就用相似度替代）。
- 流形：先用 kNN + 局部 PCA（可在 CPU 上做，稳定可解释）。
- 编辑：先做后处理最小改写，再考虑“投影约束解码”。
