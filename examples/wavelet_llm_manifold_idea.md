# 研究问题（优化版）

目标：提出一个“小波多尺度特征 + 大模型流形表征”的统一框架，用于非平稳时序信号（如振动、生理、声学）分析。

核心问题：
1. 如何用离散小波变换（DWT）稳定提取时频多尺度结构，并显式分离噪声与突变模式？
2. 如何将多尺度特征序列映射为适配大模型输入的 token/patch 结构，从而学习低维流形表示？
3. 在分类、异常检测、跨域迁移三个下游任务中，该联合表征相对纯时域/纯频域特征是否具备更高泛化性与可解释性？

约束：
- 必须给出可复现实验协议（数据划分、评价指标、统计显著性）。
- 必须给出失败判据与负对照实验。
- 必须给出计算预算与部署可行性评估。
