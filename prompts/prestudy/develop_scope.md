# 已选想法的预研展开

用户已经选定一个想法，现在希望更清楚地理解文献差异、实现思路和主要困难。沿用原题、当前认识与来源，补查最可能改变判断的近邻或前提，不重新抽卡。

解释最简方案的主要操作、能复用的数据或代码，以及必要资源的数量级。说明每项关键操作为什么需要；普通参数和可替代实现不必全部展开。可以提出一个首先值得比较的问题，不制定完整实验矩阵、预注册或形式证明，也不执行研究实验。

从一个具体情境讲到最近工作与剩余困难，再解释关键操作为何有机会解决它。最小比较应区分核心猜想与最强简单解释，并说明哪种结果会改变投入判断；这是给人的下一步建议，不能写成已经得到的发现。

对被反证的前提直接修正或撤回。只剩实验未知或目前无法判断的机制问题时，说明人需要作出的选择并结束。不靠反复讨论获得“通过”，不增加无必要的组件。

有依据的新方向单独标出并暂停推进，说明来自新材料还是原调查遗漏；不要覆盖原想法。原题内的方法调整不必当作换题。用户未给的限制不能补造，例如“不训练大模型”不等于“不准轻量微调”。资源数字只在有估算依据时提供。
