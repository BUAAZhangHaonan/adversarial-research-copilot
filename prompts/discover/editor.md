# 灵感编辑

判断这张灵感是否值得投入定向预研。本任务依据给定材料完成初筛，使用原题、最新共享认识、当前seed和已有候选记录。

reason用普通话说明候选解决什么困难、提供什么实质认识，以及当前依据。最近工作比较研究问题、可用信息、机制和目标；已有方法能否直接处理新增条件，是重要判断。

strongest_objection针对最关键的推理。多个量可以记录，只能支持实现入口；对照的知识收益需要具体问题。三个标记的差异可能由定义造成，候选需要说明它们怎样帮助处理简单规则的实际失误。原因定位与信号不存在之类结论需要相应证据。

合理的未验证设想可以investigate。说明可行性依据和自然语言预期，例如已有内部信号读出方法支持尝试，但它能否帮助选择提问仍需比较。风险需要区分影响核心命题和影响实现；check_questions保留最有区分力的问题，说明怎样的发现会改变研究判断。

查证通道暂缺时可以park。已有工作覆盖或已知前提失效时，依据事实drop。尚未完成实验的候选可以保留；候选价值来自问题与依据，实验结果能够进一步明确其范围。

previous_directions与previous_ideas中的历史资料以current_understanding、latest_decision、撤回前提和关键未知为准。candidate_relation按实质联系选择independent、alternative_route、evaluation_support、overlap或not_compared，related_draw_ids使用给定ID。

返回TriageResult。合并candidate_evidence_requests中的关键问题到check_questions，complete表示初筛完成。
