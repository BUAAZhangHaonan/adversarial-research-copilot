# read_paper

The current deployment maps this tool to ScholarAnalysis get_paper_text: it downloads and parses a paper into original Markdown text; it does not answer a research question. Prefer a confirmed standalone arXiv ID (for example, 2402.01306 or 2402.01306v2) or arXiv URL as query. Do not append the paper title, abstract, a section request or a research question to query. Resolve the paper identity first if it is not known.

After retrieval, inspect the returned original text, using read_record for stored passages, and answer the precise question, comparison or limitation in your own research analysis. Keep the returned source identity and representation when citing locators. If retrieval fails, report the actual access error and leave the affected verification unresolved. Do not claim access to unavailable tables, figures, code or full text. Metadata and service-generated analysis are not verified original passages.
